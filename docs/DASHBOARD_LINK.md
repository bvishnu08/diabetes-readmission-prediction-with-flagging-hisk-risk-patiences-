# Dashboard Link

**URL (after you start it on your computer):**  
**http://localhost:8501**

The dashboard runs only on your machine (it is not hosted online). To get that link working:

1. **Open a terminal** in the project folder.
2. **Activate the virtual environment** (if you use one):
   - **Mac/Linux:** `source .venv/bin/activate`
   - **Windows:** `.venv\Scripts\activate`
3. **Start the dashboard:**  
   `streamlit run dashboard.py`

Your browser should open to **http://localhost:8501**. If it doesn’t, open the browser yourself and go to that address.

**To stop the dashboard:** Press `Ctrl+C` in the terminal.
